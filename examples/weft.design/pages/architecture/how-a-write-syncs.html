Authorize, merge, commit

The sync service checks each op against weft.rules, then merges. Two inserts into one RGA text at different positions both survive. One Postgres transaction commits v48212–13.

Rebase to converge

The ACK carries Jonas’s v48211. Maya’s client rebases: confirmed ops first, then any still pending. It runs the same merge code as the server, so the result is identical. The op log empties.
