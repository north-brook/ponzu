# Subprocessors

These are the companies that process people's data for Ponzu. "Not in use yet" means the feature that needs them is not switched on, and they hold nothing until it is. Where we chose a region, the table names it; otherwise the company decides where it processes data.

## Services you connect

Two services you connect yourself are not our subprocessors: they work for you, under your own account with them.

- **GitHub** holds your repositories, branches and pull requests, under GitHub's terms. Ponzu reaches them through the GitHub App you install.
- **Anthropic,** for Claude Code's turns, under your own Claude account or API key and your plan's terms. (Separately, Ponzu's own Anthropic account suggests prompts for a repository; that is the Anthropic row above.)

## Other requests your browser makes

A canvas can name fonts from Google Fonts, which the apps load from Google, and images from any https address, which load from wherever they live. Their hosts learn that the canvas was opened, as they would in any browser.

The desktop app checks GitHub for updates and downloads them from there, and this website's download links point to GitHub too. GitHub sees those requests as any web host does.
