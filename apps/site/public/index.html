Your files, your workflow.

A .design is a folder on your disk. Commit it, sync it, or toss it, and embed the canvas in your own product.

~/code/fernwood
├─ src/
└─ design/fernwood.design
   ├─ tokens.css
   └─ pages/home/hero.html
$ git diff design/
- <h1>Plants that outlive
-   your lease.</h1>
+ <h1>Outlive your
+   lease.</h1>

Just HTML and CSS.

If a browser can do it, so can your design: grid, gradients, variable fonts, video, real animation. Nothing is approximated.

.card {
  animation: pop 360ms
    cubic-bezier(.3,1.6,.5,1);
}
@keyframes pop {
  from { scale: .7; opacity: .3 }
}
