Bloom

How the slice arrives and leaves. Each segment spins up into place from the centre a beat after the one before, holds, then carries on round the same way and out.

On paper

3.2s cycle

In: 0 to 0.7s. Hold. Out: 2.2 to 2.9s.

On yuzu

50ms stagger

Segment i waits i × 50ms, so the slice opens clockwise.

.seg {
  transform-origin: 32px 32px;
  animation: bloom 3.2s infinite both
    cubic-bezier(.2, .8, .2, 1)
    calc(var(--i) * 50ms);
}
@keyframes bloom {
  from { scale: 0; rotate: -60deg }
  22%, 68% { scale: 1; rotate: 0deg }
  90%, to { scale: 0; rotate: 60deg }
}

The site prints this stylesheet beside the slice it animates, in the "Just HTML and CSS" tile. Source: apps/web/components/slice-demo.ts.
